# Ilish & Co.

One-page restaurant website template with an interactive thali menu.

Demo: [https://sofikulxdd-web.github.io/ilish-restaurant-template/](https://sofikulxdd-web.github.io/ilish-restaurant-template/)

A fictional site for a Bengali fish kitchen. Pick a dish and it lights up on the plate.

Plain HTML, CSS and JavaScript in one file, with no build step. It works on phones and respects reduced-motion settings.

More templates: [sofitechllc.com/stores](https://sofitechllc.com/stores/)
